# Rutina KS — Glúteos y zona lumbar

Rutina de KS, focalizada en glúteos y para mejorar la lumbar.

Página web con un plan de gym de 5 días: ejercicios con foto, series, repeticiones y descanso, y la opción de marcar las series completadas (se guardan en el navegador).

| Día | Enfoque |
| --- | --- |
| 1 | Glúteos |
| 2 | Espalda, brazos y core |
| 3 | Glúteos y zona lumbar |
| 4 | Cuerpo completo y abdomen |
| 5 | Tren superior |

## Cómo verla

- **En local:** abre `index.html` en el navegador.
- **Online:** activa GitHub Pages en *Settings → Pages → Deploy from a branch → `main` / root*.

## Estructura

```
index.html   página completa (HTML, CSS y JS)
img/         fotos de los ejercicios
```
